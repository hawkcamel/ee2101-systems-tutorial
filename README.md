# EE2101: Tutorial on Frequency Response

Eight interactive lessons covering transfer functions, complex numbers, frequency response, LTI systems, impulses, convolution, system responses, and Laplace transforms.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

The published address will be https://hawkcamel.github.io/ee2101-systems-tutorial/ once deployment succeeds.

## Files and updates

This is a static HTML/CSS/JavaScript site; no build step or package installation is required. `index.html` is the first lesson. Keep `vendor/` with the site: it contains KaTeX and its fonts and license. The `.nojekyll` file tells GitHub Pages to serve the files directly.

Edit the lesson HTML or shared scripts/styles and commit to `main` to update the site. Internal lesson links use `.html` filenames for GitHub Pages compatibility.

Progress checkmarks are saved only in the visitor’s browser. There is no student login, server database, or class-wide activity tracking.
