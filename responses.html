LESSON 07 / PREDICTING THE OUTPUT

Predicting the output.

Transform the convolution into a product, then return to the time domain.

Use multiplication to calculate the output

Convolution can be awkward to calculate directly. A Laplace transform gives us another way to describe the same signal. In this description, convolution becomes multiplication.

Multiply in the Laplace domain; take the inverse transform to obtain the time response. We assume the system starts at rest and use values of s for which the transforms exist. The next lesson explains this range of values, called the region of convergence.

Do not confuse these two inverse transforms. A step has X(s) = 1/s; an impulse has X(s) = 1.

One system, two complementary descriptions.

Assume a causal, linear time-invariant system initially at rest. Lowercase letters denote time signals; uppercase letters denote their unilateral Laplace transforms. The unit step u(t) is zero before t = 0 and one after it.

LAPLACE DOMAIN · COMPLEX VARIABLE s

This gives the complete output caused by the input when the system starts at rest, including its initial changes. This is called the zero-state response. If the system already stores energy, such as a charged capacitor, we must also add the output due to that initial energy.

TIME DOMAIN · REAL VARIABLE t

The same relationship is convolution in time. Some systems also pass a scaled copy of the input straight to the output. This is called direct feedthrough, and it can make the output jump immediately when a step is applied.

4. What frequency response predicts

Why is the sinusoidal formula valid?

For the complex exponential ejω₀t, a stable LTI system multiplies the complex amplitude by H(jω₀). Taking the imaginary part gives the sine response; the real part gives the cosine response. For an input switched on at t = 0, the full response also contains a transient that decays for stable poles. The steady-state formula alone is therefore not the startup response.
