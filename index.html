LESSON 01 / FUNCTIONS & ROOTS

Frequency response.

Start with a complex function. Learn its geometry. Then discover how it describes a system.

First, what is H(s)?

Formally, H(s) is the transfer function of a linear time-invariant (LTI) system in the Laplace domain, defined with zero initial conditions.

If that sentence is unfamiliar, don’t worry. We will unpack it in What is a system? and Predicting the output. For now, H(s) is a function: put in a complex number s, and calculate another complex number, H(s). As with any fraction, we must check that its denominator is not zero.

The number s tells us where to evaluate H. Later, we will use a separate symbol, x(t), for the signal entering a system.

A useful family: rational functions

In this tutorial, H(s) is one polynomial divided by another polynomial. This is called a rational function. Many circuit models have this form.

Zeros

At s = z₁, the factor (s − z₁) becomes zero, so H(s) = 0, provided the denominator is not also zero. That is why we call z₁ a zero. The same applies to the other numerator roots.

Poles

As s approaches a denominator root p₁, the denominator approaches zero. If no numerator factor cancels it, |H(s)| grows without bound. We call p₁ a pole. At the pole itself, the fraction is undefined.

What if a pole and zero coincide?

Suppose H(s) = (s + 1)/[(s + 1)(s + 2)]. For s ≠ −1, cancelling (s + 1) gives H(s) = 1/(s + 2). As s approaches −1, this approaches 1, rather than growing without bound. So −1 is not a pole of the simplified function. Direct substitution in the original fraction gives 0/0; simplify first when studying the limit.
