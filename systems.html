LESSON 04 / WHAT IS A SYSTEM?

What is a system?

A function can map numbers to numbers. A system maps an entire input signal to an output signal.

Put a signal in. Get a signal out.

A signal might describe voltage, temperature, sound pressure, or a stream of orders over time. A system may have memory: its output now can depend on inputs from earlier times.

An ice-cream shop with a memory

A simple price rule maps “$3” to “one ice cream”. For a system analogy, imagine a ledger of orders arriving throughout the afternoon. The input is the order history; the output is the fulfillment history.

Why linear and time-invariant models are useful

Linear means that doubling an input doubles its output, and adding two inputs adds their outputs. This rule is called superposition. We compare these responses with the system initially at rest.

Time-invariant means the system follows the same rule whenever we apply the input. If we apply the same voltage waveform five seconds later, we get the same output waveform five seconds later.

Optional: the precise definitions and counterexamples

y(t) = x(t)² is nonlinear: doubling x quadruples y. The rule y(t) = t x(t) is linear but time-varying: its gain depends on the clock. The zero-state RC circuit has both properties.
