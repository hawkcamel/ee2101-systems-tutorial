LESSON 05 / BUILDING WITH IMPULSES

From a table to a signal.

A table records a signal at selected times. We will use those values to describe the signal as a sum of simple inputs.

1. Start with a lookup table

Suppose we measure a voltage every Δt seconds. Each row gives a time tₖ and the measured value f(tₖ). Between measurements, one approximation is to hold each value constant over a short interval. This gives the rectangular approximation below.

Choose a signal and change the spacing. Click a time in the table, or use the sample slider, to select one rectangle. All three example signals are taken to be zero outside −5 ≤ t ≤ 5.

Grey: original signal. Teal: values held over each interval. Purple: selected rectangle. Samples are taken at the centre of each interval.

The selected rectangle has height f(tₖ) and width Δt. Its signed area is therefore f(tₖ)Δt. A rectangle below the axis has negative area.

2. Keep the area; narrow the pulse

Now replace that one rectangle by a narrower pulse centred at the same time. Keep its area wₖ = f(tₖ)Δt unchanged. Halving the width doubles the height. Try this with both a positive and a negative sample.

In the limit as its width tends to zero, this is an impulse of area wₖ at time tₖ. We write it as wₖδ(t − tₖ). The symbol δ is the Dirac delta. A unit impulse has area 1; multiplying it by wₖ gives area wₖ.

An impulse is an ideal mathematical input. It has no ordinary finite height, so we draw an arrow and label its area. The pulse above is an approximation to it. Its vertical axis rescales as the pulse gets taller.

Why area, rather than height?

A very short current pulse can deliver a finite charge to a capacitor: charge is the integral of current over time. Pulses with the same area deliver the same charge, even when their widths and heights differ. The impulse idealisation keeps that finite area while taking the duration to zero.

Mathematically, the delta is a distribution. Its meaning is specified through integration, rather than a finite value at every point.

3. One impulse for each row

Apply the same construction to every row of the table. Each time tₖ supplies an impulse; the table value and spacing supply its area wₖ = f(tₖ)Δt.

These arrows do not trace the original curve. They preserve the area contributed by each small interval. As the spacing decreases, there are more impulses, each with a smaller area. This is why the factor Δt must remain in the formula.

4. Add the responses to those impulses

Suppose a system, initially at rest, responds to a unit impulse with h(t) = e⁻ᵗu(t). An impulse applied later produces the same response later. Multiplying the impulse area multiplies the response by the same amount. These two statements use time invariance and linearity.

Each row of the table now contributes one shifted response. Add them to estimate the output. The purple curve shows the contribution from the selected row. Try a smaller sample spacing and compare the total with the dashed curve.

Teal: sum of responses to the sampled impulses. Dark dashed: response to the original signal, calculated by numerical integration. Purple: the selected impulse’s response.

In the limit, the sum of responses becomes the convolution integral. The next lesson examines this calculation in more detail.
